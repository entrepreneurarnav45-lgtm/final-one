Dr. Dordi's Dental Hub website.
Upload index.html and .nojekyll to the root of the GitHub repo (single file, videos embedded).
GitHub Pages: Settings > Pages > Deploy from branch > main > /(root).

ADDING A NEW GOOGLE REVIEW
Open index.html, search for NEW_REVIEWS and paste one line per new review, e.g.
  {name:"Patient Name",topic:"Short line about the visit",url:"link to the review on Google Maps"},
Each line adds a card (newest first) and raises the Google review count by 1 (base: 199).
